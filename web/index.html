Bulk add labels

One label per line. Put | inside a line for a second text line. New labels copy the style of the selected label.

Tape colours

The PT-D600 reports the tape's width and type but not its colours, so pick them here. TapeDeck remembers your choices and offers the ones you've used before first when it sees the cover open or the cassette change.

Printing from other apps

POST a JSON text job, a binary PBM (P4; height = dots across the tape) or a TDJ1 job to /api/print. POST to /api/save instead (or send X-Print: 0) to store it in the history without printing. If an API key is set in Setup, send it as an X-API-Key header.
